# Objective 2 Final Locked-Test Comparison

This directory contains the aggregate final comparison of the frozen CNN, Attention-CNN, compact ViT, GCN and GAT candidates. Validation-selected thresholds were reused without change. The test cohort was evaluated once per model and was not used for training, threshold tuning or model selection.

No patient/image identifiers, medical images, private manifests or case-level predictions are included.
