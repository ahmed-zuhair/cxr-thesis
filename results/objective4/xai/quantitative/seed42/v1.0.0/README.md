# Objective 4 Quantitative XAI Aggregate Results

This public artifact contains aggregate explainability results for
DenseNet-121 on 240 validation cases.

Methods:
- Grad-CAM
- Integrated Gradients

The package contains aggregate metrics and figures only.
It contains no medical images, masks, saliency maps, patient identifiers,
image identifiers, private manifests, or case-level predictions.

The locked test set was not accessed or evaluated for this artifact.
